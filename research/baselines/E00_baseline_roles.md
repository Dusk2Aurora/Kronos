# E00 策略与比较定位

E00 有六类基线，只有普通特征门控需要训练模型。所有组合由同一官方 Freqtrade 引擎执行，每个开发测试季度独立重置 10,000 USDT 余额，可交易比例99%，杠杆1x，最大持仓一笔。费用代理每边7 bps和14 bps，实际永续资金费用另计。数据、信号、退出和费用完整定义见 `research/configs/initial_experiment.yaml`，历史结果见 `research/initialization/E00_results.md`。

| 基线 | 信号、仓位和退出 | 比较定位 |
|---|---|---|
| 现金 | 不开仓，净收益0 | 判断承担风险后的收益是否优于不交易；假设不计现金利息 |
| 买入持有 | 每折首个可用入场做多，使用可用资金，持有至季度最后一小时开盘 | BTC多头市场暴露参照；不用于声称与4h母策略拥有相同持有期 |
| 固定动量 | UTC04/12/20决策，最新完成K线与24h前收盘价比较，上涨做多、下跌做空；下根K线开盘入场，持4h；全额可用资金 | 参与/跳过研究的母策略；保留其负结果，不以调参改善母策略作为门控成功 |
| 固定半仓 | 与固定动量同样的机会、方向和4h退出，每次使用一半建议仓位 | 区分降低单次资金暴露造成的变化，与筛选信息造成的变化 |
| 波动率目标 | 同固定动量，过去72小时对数收益标准差×sqrt(8760)为年化波动率；仓位比例min(1,0.20/年化波动率)，零波动率时取1；持4h | 普通历史波动风险控制；20%是仓位缩放目标，不是已保证的实际组合波动率 |
| 普通特征门控 | 13项历史特征，经训练折StandardScaler，正则logistic预测单笔基础净收益>0的概率；概率>=0.5参与，全额可用资金，持4h | 原方案下常规行情信息参照；8/1091次参与是稀疏诊断，不证明缺失信号或策略盈利 |

普通特征为：1/4/12/24/72/168h对数收益，24/72/168h小时收益波动率，24h平均(high-low)/close，成交量24h均值/168h均值，真实成交额24h均值/168h均值，以及24h动量方向。模型不反转母策略方向，不选择仓位或退出时点。

原 logistic C=[0.1,1,10]、种子[17,29,43]，按前一季度验证logloss选择，阈值固定0.5；每折只用更早历史训练，预处理只拟合训练折。14 bps压力复用基础模型和同一信号。该模型没有使用Kronos，亦没有使用未来资金费用作特征。

E00R 是独立修订协议：净收益 Ridge + 原13项消融/主19项方向交互，验证固定分位数检验筛选信息、预测净收益>0检验经济准入，并加入常数、随机与周期对照。它的定位是公平解释后续表征增量，不能因为相对亏损动量少亏就宣称有效，也不要求普通基线先盈利才研究Kronos。配置见 `research/configs/baseline_revision_v2.yaml`。

后续 E01R 在同样普通特征上追加预训练冻结Kronos表征，E02R追加随机冻结骨干表征并保留预训练tokenizer，使用同一预测头、目标和选择范围。该对照隔离的是骨干预训练增量，不能单独归因于tokenizer预训练。最终holdout封存；当前仍止于冻结表征提取之前。
