# 实现与失败记录

- 协议在目标计算前锁定，固定 96 个候选；正式拟合前不使用开发测试结果修改设计。
- 新合成测试首次执行发现 `build_labels` 的时间戳 JSON 序列化只支持 CSV 字符串，传入 pandas Timestamp 会失败。保存原异常作为工程记录，修正为统一 UTC 字符串，不改变价格、标签、模型或筛选语义；重新运行同一测试。
- Windows 默认沙箱启动发生 helper_unknown_error；经自动审批的显式升级执行可正常访问授权仓库，不影响研究环境或数据。未重装研究依赖。
- 原 M0 验收器是阶段专用程序。本轮使用 `M0_state_transition.json` 保存并由原验收报告 hash 证明的历史 YAML 重放；通过内存重定向读取和配置 hash，不修改当前配置，也不关闭任何原断言。后续报告区分该历史重放与当前第二项验收。
- 原 `verify_e00r.py` 直接运行的数值/因果断言通过后，在末尾因当前配置已不是 `ready_to_encode` 而触发历史阶段断言；原失败日志保留。使用 E00R 注册表中完整、hash 验证的当时配置重放整个原检查，不删除断言，也不回退现行研究配置。
- 正式拟合后的 scaler 均值复核首次失败：pandas 对 float32 隐藏列做均值，与模型注册的 float64 预处理最大差 `6.104751293367627e-08`。独立复核改为明确先转 float64 后计算，差为 0；原 `rtol=1e-12, atol=1e-12` 断言保持不变，没有放宽标准。模型、候选、目标及统计均未改动，也未重新拟合候选。
- 确定性验收首次使用 pandas 默认 CSV 浮点解析，目标值与生成时的 double 最大差约 `9.99e-17`，因此不满足“完全相同输入”的精确复算前提。改为 `float_precision='round_trip'` 读标签后，重新计算系数及截距逐位相等；精确相等断言未放宽。未来扰动比较也使用两个原始计算特征路径比较，避免拿 CSV 有损解析路径与直接计算路径当成完全相同输入。正式模型及评估保持原版本，额外拟合仅为验收重放，不新增候选。
- 报告绘图首次使用 `DataFrame.at` 属性访问名为 `at` 的时间列，引发属性冲突；改为显式 `frame['at']`，不影响研究CSV。图表版式候选保留为 `tmp/pdfs/frozen_risk_02_v1/layout_candidate_01/02.pdf` 及相应 manifest；最终版本修正季度图日期刻度重叠，并按独立审查意见明确极端事件表控制=R1，数值与结论未变。
